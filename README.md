# Git 参考手册

这是一个简明且全面的 Git 中文参考手册，旨在帮助开发者快速查找常用的 Git 命令、理解核心概念、掌握标准工作流以及应对常见的错误场景。

## 📚 包含的内容模块

- **基础操作**：克隆、配置、提交、状态查看。
- **分支与合并**：新建分支、切换、合并（Merge/Rebase）。
- **远程与 GitHub**：关联远端、拉取验证、推送。
- **补救与撤销**：丢弃本地更改、撤销提交、历史回退。
- **概念辨析**：工作区 vs 暂存区、Merge vs Rebase 等。
- **图解动画**：直观演示 Git 内部指针与对象变动历史。
- **日常标准工作流**：从开发新功能到最终合并的最佳实践。

## 🌟 功能特色

- **一页式设计**：所有的参考信息和指令都整合在一个 HTML 文件中，轻量且加载迅速。
- **分类清晰**：涵盖了基础操作、分支与合并、远程协作、补救操作、概念辨析、标准工作流等。
- **图文并茂 (包含图解动画)**：对合并、分支等核心概念配有视觉化的步骤和动画解释更易于理解。
- **VS Code 专属指南**：包含在 VS Code 中操作 Git 的详细指南，提升日常开发效率。
- **场景速查**：提供真实的开发场景帮助速查解决方案。

## 🚀 使用指南

本项目是一个纯前端单文件，无需安装任何依赖或构建工具。您可以通过以下两种方式使用：

### 方式一：直接在线访问（推荐）
在浏览器中直接打开：[https://paul-gk.github.io/Git_Tutorial/](https://paul-gk.github.io/Git_Tutorial/)

### 方式二：本地浏览
1. **克隆仓库到本地**：
   ```bash
   git clone https://github.com/paul-gk/Git_Tutorial.git
   ```

2. **运行/浏览**：
   在浏览器中直接双击打开下载下来的 `index.html` 文件即可。
